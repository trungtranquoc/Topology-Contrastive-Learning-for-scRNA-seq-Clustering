# TopoCLR: Topology Contrastive Learning Regularizer for scRNA-seq representation learning

---

This repo proposes code for TopoCLR: Topology Contrastive Learning Regularizer for scRNA-seq representation learning. Beside, experiments on 6 models (contrastive-sc, scCCL, scNAME, scGPCL, scMMN, and scAGCL) are included, where the TopoCLR is added into their training to improve clustering result. The experiments are run on 24 scRNA-seq datasets, which can be found in [Kaggle](https://www.kaggle.com/datasets/trungtranhcmut/scrna-seq-datasets-topology-contrastive-learning).

## Abstract

Low-dimensional representation learning is essential for capturing complex cellular heterogeneity and enabling downstream tasks, such as cell-type clustering, in high-dimensional single-cell RNA-sequencing (scRNA-seq) data. While contrastive learning has emerged as a powerful paradigm for single-cell representations, standard instance-level objectives optimize local instance similarity at the expense of global manifold structures. To address this limitation, we introduce TopoCLR (Topological Contrastive Learning Regularizer), a generalizable, plug-and-play topological regularization strategy that explicitly aligns the persistent homology of augmented data views. We demonstrate the versatility of TopoCLR by integrating it into 6 diverse contrastive architectures, spanning both deep neural networks and graph neural networks. When evaluated on downstream clustering across 24 real scRNA-seq datasets, empirical results show that TopoCLR consistently boosts clustering performance—achieving average gains of up to 10.72\% in NMI and 26.46\% in ARI—and outperforms state-of-the-art baselines on 19 out of 24 datasets. Furthermore, extensive robustness evaluations under controlled input perturbations confirm that TopoCLR stabilizes continuous latent representations and prevents topological manifold degradation. Ultimately, TopoCLR provides a model-agnostic loss module for global structural preservation in contrastive learning, establishing a robust new benchmark for single-cell transcriptomics.

## Topology Signature Loss function


**Topological Contrastive Alignment**. Let $Z_1$ and $Z_2$ denote the latent embeddings generated by the encoder from two augmented views, with corresponding pairwise distance matrices $\mathcal{M}^{Z_1}$ and $\mathcal{M}^{Z_2}$. The dot product is used to define distance of any two points: $\text{sim}(u, v) = u^T v / (\|u\| \|v\|)$ denotes the dot product between $\ell_2$ normalized vectors, measuring the cosine similarity between the representations. Independently applying the Vietoris-Rips filtration to each distance matrix yields two distinct filtrations. Computing the persistent homology of these filtrations produces the persistence diagrams $PD^{Z_1}$ and $PD^{Z_2}$, alongside their respective sets of critical edge indices $\pi^{Z_1}$ and $\pi^{Z_2}$. 

Let $\Pi = \pi^{Z_1} \cup \pi^{Z_2}$ denote the combined multiset of all critical edge indices from both augmented views. The topological contrastive alignment loss can be defined over this combined set: $\mathcal{L}_{topo}(Z_1, Z_2) = \frac{1}{2} \| \mathcal{M}^{Z_1}[\Pi] - \mathcal{M}^{Z_2}[\Pi] \|^2$


## Project contents

 
- `utils/`: contains preprocessing code and other supported functions.
- `experimental_notebooks/`: contains experimental codes of 6 scRNA-seq models that are copied directly from authors' repo. `ToplogySignatureLoss` is added into their training to improve clustering result.
- `topology_signature.py`: Contains `TopologySignatureLoss` function that use Persistence Homology to refine code
